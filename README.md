# 截图套壳

把任意截图套进一个 macOS 风格的窗口里，一键导出高清图片。整个过程都在浏览器本地完成，图片不会上传到任何服务器。

## 功能

- 三种载入方式：点击选择、拖拽图片、`⌘V` 直接粘贴截图
- 两款框架主题：深色 / 浅色
- 图片比例自动适配，任何尺寸的截图都能套上框架
- 保留窗口圆角，红黄绿三个控制点
- 阴影可开关、可调柔和度与浓度
- 圆角大小、标题栏高度、边框留白均可微调
- 导出格式可选 PNG（无损）或 WebP（体积更小），WebP 画质可调
- 导出倍率 1x / 2x / 3x，满足高清需求

## 技术栈

Vue 3 + TypeScript + Vite。核心渲染用 Canvas 分层绘制：窗口背景与阴影 → 裁剪圆角 → 绘制标题栏和截图 → 绘制控制点，因此导出的图片圆角完整、清晰度可控。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

构建生产版本：

```bash
npm run build
```

产物在 `dist/`。

## 使用

1. 在左侧上传、拖入或粘贴一张截图
2. 选择深色或浅色框架，按需调整圆角、阴影等参数
3. 选择导出格式与倍率，点击右上角「导出」
